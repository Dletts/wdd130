Task 3: Nesting Block in Inline

placing a <div> inside a <span> element.

What error or layout issue do you see? A div element is placed inside a span, which is invalid HTML. Block-level elements like div should not be nested inside inline elements like span. This can cause unpredictable rendering or validation errors. Why does this happen? Because of how browsers define block vs inline content.
